# Simple-Java-App

A production-ready Java microservice built with Spring Boot, ready for Kubernetes deployment.

## 🚀 Quick Start

### Prerequisites
- Java 17+
- Maven 3.9+
- Docker (optional)
- kubectl + Kubernetes cluster (for K8s deployment)

### Build & Run Locally

```bash
# Clone the repository
git clone https://github.com/ravindrababuweblogic/simple-java-app.git
cd simple-java-app

# Build
mvn clean package

# Run
java -jar target/simple-java-app-1.0.0.jar

# Application available at http://localhost:8080
```

### Using Docker

```bash
# Build image
docker build -t simple-java-app:latest .

# Run container
docker run -p 8080:8080 simple-java-app:latest

# Test health check
curl http://localhost:8080/health
```

## 🐳 Kubernetes Deployment

### Prerequisites
```bash
# Set up your kubeconfig
kubectl config use-context <your-cluster>

# Ensure you have container registry access
```

### Deploy

```bash
# Apply all manifests
kubectl apply -f k8s/

# Verify deployment
kubectl get deployments,pods,svc -n default

# View logs
kubectl logs -f deployment/simple-java-app

# Port forward to test locally
kubectl port-forward svc/simple-java-app 8080:80
```

### Autoscaling
The HPA (HorizontalPodAutoscaler) automatically scales pods based on CPU/Memory:
- **Min replicas:** 2
- **Max replicas:** 10
- **CPU threshold:** 70%
- **Memory threshold:** 80%
